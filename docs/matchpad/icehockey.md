# Хоккей в Matchpad: опорное поведение

Сверено 14 сентября 2026 года с Matchpad `456396693599`. Общие правила форматирования
описаны в [common.md](common.md). Этот файл фиксирует поведение, на которое нужно ссылаться
при развитии плагина gmib «Хоккей».

## Тайм-аут

Кнопка тайм-аута относится к конкретной команде. `startAsyncTimeout` останавливает
работающий основной таймер, включает вторичный таймер с `autoStart` и сохраняет признак,
шёл ли основной таймер до этого. На табло основной таймер остаётся виден, а вторичный
показывается ниже между индикаторами использованных тайм-аутов команд.

При остановке или окончании вторичного таймера Matchpad возвращает управление основному.
Если основной таймер шёл до тайм-аута, Matchpad запускает его снова. Счётчик команды
увеличивается при естественном окончании тайм-аута; ручная остановка использованный
тайм-аут не добавляет. Доступность кнопки и максимальное количество определяются
выбранным регламентом и текущим этапом.

Опорные файлы:

- `src/store/game.ts`: `startAsyncTimeout`, переключение primary/secondary;
- `src/store/listeners.ts`: окончание вторичного таймера и счётчик;
- `src/app/[lang]/(console)/[mode]/game/@icehockey/Controller.tsx`;
- `src/app/[lang]/(scoreboard)/scoreboard/Scoreboard.tsx`.

## Удаления

Активные удаления идут только вместе с игровым таймером. Целые секунды всех удалений
синхронизированы с фазой основного таймера. В последнюю секунду выводятся десятые без
фазовой задержки. При нуле удаление сразу исключается из проекции табло и транспорта.
Matchpad также учитывает очередь, максимум одновременно влияющих удалений, обоюдные
удаления и составные штрафы; облегчённый плагин gmib пока оставляет сложные судейские
решения оператору.

## Текущее соответствие плагина gmib

| Область | Плагин «Хоккей» |
| --- | --- |
| Основной и вторичный таймер | Разделены; тайм-аут стартует сразу и не скрывает основное время |
| Остановка тайм-аута | Вторичный таймер сбрасывается, основной остаётся на паузе до команды оператора |
| Учёт тайм-аута | Считается использованным при запуске, включая досрочную остановку |
| Лимит | Задаётся при создании игры; общая модель поддерживает `0–9`, а не только `0/1` |
| Коррекция счётчика | Число использованных тайм-аутов можно исправить на пульте |
| Удаления | Синхронные целые секунды, десятые в последнюю секунду, исчезновение при нуле |
| Сложные правила удалений | Пока выполняются оператором вручную |

Различия по остановке и учёту тайм-аута сделаны явно: для облегчённого пульта досрочно
остановленный командный тайм-аут уже считается использованным, а игровой таймер не
возобновляется без отдельного нажатия «Старт».
