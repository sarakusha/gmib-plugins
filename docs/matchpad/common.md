# Перенесено в Matchpad

Эталонное описание теперь хранится рядом с реализацией Matchpad:

- `/docs/sports/timers.md` — направление, округление, фаза и вторичные таймеры;
- `/docs/sports/icehockey.md` — хоккейные тайм-ауты и удаления.

Этот каталог gmib-plugins содержит только ссылки и различия плагинов с эталоном.
