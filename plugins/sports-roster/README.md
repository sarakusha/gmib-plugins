# Составы команд

Общий локальный справочник участников и команд для спортивных плагинов gmib.
Не обязателен для работы `icehockey`: устанавливайте его, когда нужны сохранённые составы.

## Запуск

1. Установите gmib с Plugin API 1.1 и архив `sports-roster.gmib-plugin` через раздел «Плагины».
2. Установите спортивный плагин, например `icehockey`, и перезапустите gmib.
3. Откройте «Составы команд → Управление». Страницу можно установить как PWA средствами браузера.
4. Выберите вид спорта, добавьте команды и участников.

Без доступного спортивного плагина список новых видов спорта пуст. Ранее введённые данные
сохраняются; выключенный или удалённый вид спорта отображается как недоступный.

## Возможности

- Название, сокращение, город, цвет и эмблема команды (PNG/JPEG/WebP до 250 КБ).
- Общие участники: одного человека можно включить в несколько команд.
- Номер строкой (например `07`), позиция, капитан и участие в заявке.
- Проверка уникальности номера и участника в команде.
- Архивирование команд; редактирование имени участника применяется во всех его командах.
- Снимок заявки через сервис `sports.rosters` версии 1.0.0. Уже созданный матч не меняется
  при последующем редактировании справочника.
- Скачивание JSON-копии и транзакционное восстановление. Восстановление **заменяет** справочник;
  перед ним сохраните текущую копию. Ошибка входных данных откатывает замену целиком.

## Данные и доступ

SQLite: `<gmib userData>/plugins/.data/sports-roster/rosters.sqlite3`.
База и эмблемы сохраняются при обновлении или удалении плагина. Изменять SQLite вручную не нужно.
Для больших справочников размер HTTP-запроса ограничивается настройками сервера gmib.

Страницы, API и события доступны только с этого компьютера. Service worker кеширует оболочку,
а не команды и ответы API. Для редактирования gmib должен работать.
Доступ с сетевых планшетов пока не включён.

Разрешения: локальные HTTP-маршруты, SQLite, предоставление сервиса, список видов спорта и realtime.
Плагин не управляет NiBUS или LED-выводом.

## Разработка и проверка

Backend — автономный CommonJS в `backend/main.cjs`; UI — HTML/CSS/JS без внешних зависимостей и CDN.
Сборка из корня репозитория: `pnpm build`. Архив: `dist/sports-roster.gmib-plugin`.
Тесты: `node --test tests/roster.test.mjs` (Node 24+, встроенный SQLite используется только тестами).
В gmib SQLite предоставляет хост.
