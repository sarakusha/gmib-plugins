# Shader Screensavers

WebGL-заставки для экранов gmib с локальным предпросмотром и управлением сценой.

## Настройки

Плагин явно поддерживает удалённую конфигурацию через авторизованные маршруты:

```text
GET   /api/plugins/shader-screensavers/settings
PATCH /api/plugins/shader-screensavers/settings
```

Полная plugin-owned OpenAPI 3.1 схема доступна по необязательному авторизованному маршруту
`GET /api/plugins/shader-screensavers/openapi.json`. Она описывает только API этого плагина и не
является универсальным контрактом для остальных плагинов.

`GET` возвращает только настройки:

```json
{
  "scene": "truchet",
  "speed": 45,
  "scale": 50,
  "brightness": 85,
  "patternOpacity": 100,
  "backgroundOpacity": 100,
  "colorA": "#7cffcb",
  "colorB": "#6a5cff",
  "background": "#05070d",
  "animate": true
}
```

`PATCH` принимает любое непустое или пустое подмножество этих полей. Переданные значения
проверяются строго: `scene` должен быть `truchet`, `aurora`, `plasma` или `topography`; целые
числа остаются в диапазонах интерфейса; цвета имеют формат `#RRGGBB`; `animate` — boolean.
Пропущенные поля сохраняются. Ответ имеет вид `{ "changed": true|false, "settings": {...} }`;
повтор того же PATCH возвращает `changed: false`, а результат содержит сохранённое состояние.
Ошибки неизвестных полей и неверных значений возвращаются с HTTP 400 и полем `error`.

Запись использует атомарное `storage.update`, поэтому два частичных PATCH не затирают поля друг
друга. При изменении публикуется событие `changed`, которое обновляет локальный предпросмотр.

Удалённые маршруты доступны только через host authenticated access. Локальный control UI продолжает
использовать `GET/PUT /state`; этот маршрут остаётся локальным и сохраняет прежнее поведение. Состав
настроек является контрактом именно `shader-screensavers`; наличие такого маршрута у других плагинов
не предполагается.
