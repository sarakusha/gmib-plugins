# Хоккей

Самостоятельный плагин gmib: локальный PWA-пульт, системные игровые часы и HTML-табло для LED.
**`sports-roster` не требуется.** Можно провести игру, введя только названия команд,
а штрафы добавлять по номеру игрока без карточек участников.

## Установка и первый матч

1. Установите gmib с Plugin API 1.1 и архив `icehockey.gmib-plugin` через раздел «Плагины».
2. Перезапустите gmib и нажмите «Хоккей → Управление».
3. Нажмите «Взять управление», затем «Новая игра». Введите названия команд и длительность периода.
4. Кнопками +/− меняйте счёт, «Старт / Пауза» управляйте временем.
5. «Добавить штраф» принимает команду, номер игрока и длительность. Состав для этого не нужен.

Пульт доступен по `http://localhost:<порт gmib>/plugins/icehockey/control.html`.
Открытая через gmib ссылка уже содержит правильный порт. PWA устанавливается средствами браузера.
Шрифты и скрипты локальные, интернет для работы не требуется.

## Составы — необязательное расширение

Установите `sports-roster` и перезапустите gmib. В пульте появятся ссылка «Составы команд»
и выбор команд в форме новой игры. Можно снять галочки с игроков, не участвующих в этой игре.
Оставьте «Вручную», чтобы пользоваться суперлёгким режимом и с установленным справочником.

Отсутствующий, выключенный, несовместимый или не запустившийся `sports-roster` не блокирует хоккей.
Заявка копируется в матч вместе с именами, номерами и оформлением. Правки справочника не меняют
уже созданный матч. Эмблемы сохраняются в снимке; текущий LED-макет выводит названия и номера.

## Ведение матча

- Один активный матч, хозяева/гости, счёт 0–999, период 1–99. Нажмите на число счёта для прямого исправления.
- Периоды и овертайм переключает оператор; перед сменой периода остановите игровые часы.
- Коррекция времени в формате ММ:СС доступна на паузе.
- Перерыв и 30-секундный тайм-аут имеют собственное время. После «Вернуться к игре»
  восстанавливается остаток игрового времени; запуск часов всегда явный.
- Штрафы 2/4/5/10 минут или своя длительность. Можно исправить остаток, снять штраф или отложить
  его начало. Штрафы уменьшаются только при работающих игровых часах и сохраняются между периодами.
- При нуле штраф удаляется из состояния, пульта и вывода. В пульте видно до 30 штрафов;
  LED и NiBUS показывают первые два активных на сторону. Отложенные штрафы ждут ручного запуска.
- «Показать составы» переключает основную LED-страницу. Страница `rosters.html` всегда показывает составы.
- «Завершить» сохраняет итог. «Сохранённые игры» позволяет открыть старую игру; для продолжения
  завершённой нажмите «Возобновить».
- «Отменить действие» возвращает снимок перед последней командой и останавливает часы.
  Это также возвращает время снимка: после отмены обязательно проверьте его.

Совпадающие штрафы, освобождение после гола, двойной малый как последовательность частей,
буллиты и другие судейские решения **не автоматизированы**. Оператор корректирует счёт и штрафы вручную.
Турниров, официального протокола и аппаратного HID-таймера нет.

## Вывод на LED и фоновый запуск

1. В gmib → «Вывод» настройте экран: дисплей, координаты и размер LED-области.
2. В PWA откройте «Вывод и NiBUS», выберите этот экран и нажмите «Включить табло».
3. При необходимости включите «Включать вывод при запуске gmib».
4. Для запуска gmib со скрытым главным окном включите существующую настройку gmib «Автозапуск».

Вывод использует обычную страницу gmib и не требует NiBUS. Отключённый монитор не подменяется
основным дисплеем; статус доступен в настройках пульта. Геометрия задаётся в gmib, не в браузере.
Кнопка «Выключить» также отменяет автоматическое включение этого профиля.

## NiBUS

Включается отдельно в настройках пульта. Выберите соединение существующего NiBUS-сервиса gmib,
адрес назначения (по умолчанию broadcast `FF:FF:FF:FF:FF:FF`) и разрешите передачу.
Если список ещё пуст, закройте и повторно откройте настройки после обнаружения соединений.

Профиль `matchpad`: reports 5/50 (время), 6/7 (счёт), 8 (период), 19/20 (названия), 28 (штрафы).
Поддерживаются два активных штрафа на команду, числовые номера 0–99. Иные номера разрешены
в PWA/HTML-табло, но требуют исправления для NiBUS. Названия кодируются в Windows-1251
с ограничением протокола до 61 байта. Ответ табло не подтверждает эти широковещательные reports:
статус очереди не является подтверждением физического отображения.

Соединение может принадлежать одному отправляющему плагину. Пакеты формирует ядро gmib;
плагин не получает serialport или RAW-доступ. Ошибка NiBUS не останавливает игру.
После переподключения ядро отправляет актуальное состояние. Входящие reports автоматически
не изменяют матч; источник истины — системные часы и команды оператора.

## Сохранение, связь и управление

SQLite: `<gmib userData>/plugins/.data/icehockey/matches.sqlite3`.
База переживает обновление и удаление плагина; настройки интеграций лежат рядом в `state.json`.
Команды и состояние записываются одной транзакцией, повторная команда не удваивает изменение счёта.

Часы работают в основном процессе gmib и не останавливаются от закрытия браузера или сворачивания окна.
Изменение календарного времени ОС не меняет отсчёт. При работе часы сохраняются примерно раз в секунду,
при командах и штатном выходе — дополнительно. При ошибке контрольной записи часы останавливаются.
После аварии восстанавливается последний сохранённый снимок **на паузе** с просьбой проверить время.
При сне компьютера также требуется проверка времени. Секундный интервал не гарантирует секундную
потерю при зависшем диске или процессе.

Один браузер владеет пультом; остальные — просмотр. «Освободить пульт» передаёт возможность управления.
После пропадания клиента аренда управления истекает через 15 секунд; она не останавливает матч.
При потере связи команды не кешируются и не отправляются позднее. LED ограничивает интерполяцию
двумя секундами и показывает потерю связи, когда новые данные не приходят более трёх секунд.
Обновление service worker применяется после закрытия использующих старую версию окон.

## Ограничения выпуска и проверка

UDP и управление с сетевых планшетов пока не включены. Страницы, HTTP и realtime доступны локально.
Для LAN-планшетов потребуется отдельный этап HTTPS, авторизации и передачи управления.

Backend — CommonJS в `backend/`, UI — автономный HTML/CSS/JS без npm runtime и CDN.
Из корня репозитория: `pnpm test`, `pnpm validate`, `pnpm build`.
Архив: `dist/icehockey.gmib-plugin`. Тесты используют Node 24+ и встроенный SQLite;
в gmib используется драйвер хоста.

Проверены модель времени/штрафов, самостоятельный запуск без сервиса составов,
дедупликация команд, конфликт revision, сохранение, восстановление и остановка при сне ОС. На локальном браузерном стенде
проверены создание ручного матча, счёт, отсчёт времени, штраф по номеру и обновление LED-страницы, в том числе в размерах 480×192 и 320×128.
Совместимость кодеков проверяется тестами ядра gmib по эталонным данным Matchpad.
Физическая задержка и показ на конкретном LED/NiBUS-оборудовании требуют отдельной проверки.
